# Striff.io

Marketing + reference site for Striff diagrams.

## Getting started

```bash
npm install
npm run dev
```

Open http://127.0.0.1:4321

## Build

```bash
npm run build
npm run preview
```

## Deployment

Configured for Netlify via `netlify.toml`. Set environment variables in Netlify:
- `PUBLIC_POSTHOG_PROJECT_TOKEN`
- `PUBLIC_POSTHOG_HOST`
