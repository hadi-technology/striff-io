# Striff.io

Marketing + reference site for Striff diagrams.

## Requirements
- Node.js 18+
- npm

## Getting started

```bash
npm install
npm run dev
```

Open http://127.0.0.1:4321

## Build

```bash
npm run build
npm run preview
```

## Notes
- Diagram image: `public/diagram-placeholder.svg`
- Toggle plugin state in `src/pages/index.astro` (`pluginReleased`)
