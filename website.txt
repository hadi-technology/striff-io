5. How to Read a Striff (reference section)

This section doubles as documentation.

Intro line:

Each Striff is a structural diff diagram derived from code changes.

Numbered explanations (matching diagram callouts):

① Change coloring
Green = added, red = removed, amber = modified, gray = unchanged context

② UML-based class structure
Classes and relationships rendered in a familiar UML-style layout

③ Object-oriented metrics
Selected metrics highlight growth, coupling, and architectural hot spots

④ Class comments
Docstrings and comments surface intent and design rationale

⑤ Summarized components (…)
Unchanged or irrelevant parts collapsed to preserve readability

UI behavior:

Desktop: list + diagram

Mobile: accordion
